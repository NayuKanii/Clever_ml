# Clever_ml
Clever is a dice game in which the goal is to get as many points as possible. I want to discover, through use of machine learning, if there is a dominant strategy while playing the game. 

To do this I intend to do the following:

  - Program the first edition of Clever
  - Teach an "AI" to play the game
  - Store data from play sessions for analytic use
  - Use PowerBI to analyse the data
